# Markaz Network downloads

Public installers and user guides for Markaz Network. The development source repository is private.

## Current release: 1.0.0 (Windows x64)

Download the ZIP from Releases, extract the entire folder, then open **Markaz Network.exe**. Python is included. The application is unsigned. Keep its console window open while using the dashboard.

This release includes the original Markaz campus management profile when the private campus CLI is already installed. Other MikroTik networks have SSH inventory access. **It does not yet provide the planned comprehensive RouterOS management or hosted workspace pairing.**

Create your local administrator account on first run, save its authenticator key, and sign in. Local accounts belong to this installation and are separate from website accounts. The dashboard works without WAN connectivity if the computer can reach the router on its LAN or VPN.

Never share router credentials in issues. Back up your local account data before replacing an installation. Public general-purpose server packages will be published after their installation and upgrade checks pass.
